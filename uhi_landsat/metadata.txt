about=Enter a date, location name, latitude/longitude and radius. The plugin finds the least-cloudy Landsat 8/9 scene within +/-7 days (USGS LandsatLook or Element84 Earth Search STAC), reads bands 10 and 11 from the first working source (local folder, AWS S3 requester-pays, or USGS HTTPS with a session cookie), computes land surface temperature with a split-window algorithm in memory-bounded blocks, and adds styled LST (°C) and UHI class layers without freezing QGIS. Output GeoTIFFs carry full provenance. See the README for data-access requirements.
